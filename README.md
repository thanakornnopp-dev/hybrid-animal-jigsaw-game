# 🎬 Hybrid Animal Jigsaw Game (เกมเปิดป้ายทายภาพสัตว์มีม 36 ช่อง)

> **Spectacular Grand Cinema & Broadcast Studio Edition**  
> เว็บเกมเปิดป้ายจิ๊กซอว์ทายภาพสัตว์สายฮาและสัตว์ตัดต่อกวนๆ รวม 35 ภาพ พร้อมระบบเสียงเอฟเฟกต์ พลุไฟเฉลิมฉลอง และลำแสงสปอตไลต์เวที 4 ทิศทาง

🌐 **Live Game URL:** [https://thanakornnopp-dev.github.io/hybrid-animal-jigsaw-game/](https://thanakornnopp-dev.github.io/hybrid-animal-jigsaw-game/)

## ✨ ไฮไลต์ฟีเจอร์เด่น (Key Features)

1. **คลังภาพสัตว์สุดฮา 35 ภาพ (35 Hybrid & Meme Animals):**
   - รวบรวมภาพสัตว์แปลก สัตว์ตัดต่อสายมีม และภาพสัตว์ชวนขำขันรวม 35 ภาพ
   - สุ่มภาพไม่ซ้ำกันในแต่ละรอบ (Fisher-Yates Shuffle) รอบละ 1–35 ภาพ
   - ฝังภาพแบบ Base64 100% ใช้งานออฟไลน์ได้โดยไม่ต้องเชื่อมต่ออินเทอร์เน็ต

2. **แผ่นป้ายจิ๊กซอว์ 36 ช่องปิดสนิท 100% (Zero Gap):**
   - แผ่นป้ายขนาด $6 \times 6$ แผ่น ประกบชิดสนิทแบบ Edge-to-Edge ไม่มีรูเว้นว่าง และไม่เห็นภาพลอดผ่านก่อนเปิด
   - ตัวเลขสลักจมลึก (Inset Engraved Letterpress) สีทองคำเปลวเรืองแสงอร่าม ขนาดใหญ่ ชัดเจน อ่านง่ายจากระยะไกล
   - แอนิเมชันเปิดแบบ **3D Mechanical Studio Flip 180°** มีมิติความลึกเสมือนแผ่นป้ายบนเวทีจริง

3. **เวทีบรอดแคสต์สตูดิโออลังการ (Volumetric Stage Lighting):**
   - ลำแสงสปอตไลต์เวทีเคลื่อนไหวกวาดตัดกัน 4 ทิศทาง (ทองแชมเปญ, ฟ้าไซอัน, ชมพูมาเจนต้า, ทองคำ)
   - ขอบเวทีมีไฟนีออนสายรุ้ง (360° Rainbow Neon Chaser Rim) เรืองแสงหมุนรอบกรอบกระดานตลอดเวลา
   - ปรับสัดส่วนตามขนาดรูปภาพจริงอัตโนมัติ (ไม่มีการครอบตัด และไม่มีขอบดำ)

4. **ระบบเฉลิมฉลองสุดยิ่งใหญ่ (Grand Fireworks & Fanfare):**
   - เมื่อกด **"เปิดทั้งหมด"** หรือเปิดป้ายครบ 36 แผ่น:
     - พลุดอกไม้ไฟระเบิดพุ่งขึ้น 8 ระลอกทั่วทั้งหน้าจอ พร้อมประกายไฟระยิบระยับ (Glitter Sparkles)
     - บรรเลงบทเพลงเฉลิมฉลองแบบดีใจ (Joyful Fanfare Melody) สดใส ยิ่งใหญ่ สมจริง
     - สังเคราะห์ผ่าน Web Audio API เสียงคมชัด 0 Latency ไม่ต้องพึ่งพาไฟล์ภายนอก

5. **ปุ่มลัดคีย์บอร์ด (Keyboard Shortcuts):**
   - `Spacebar`: ไปยังภาพถัดไป
   - `U`: ย้อนกลับ (Undo การเปิดป้ายล่าสุด)
   - `R`: เปิดทั้งหมด (Reveal All)
